PHP RCE vulnerabilities

From reports by OpenAI, wiz.io, Simon Willison · Oct 21

PHP's October 21 security release fixed two remote code execution vulnerabilities across the PHP 8.x line, and Simon Willison says exploits have been circulating since the night before because of a leak in the coordinated disclosure process.1 According to the PHP Foundation, the two CVE IDs began circulating on October 20 with a wrong release time and a wrong CVSS score of 10.0, when the actual score is 9.2.23 The PHP project responded by bringing its pre-announcement forward and moving the release a day earlier, to October 21.4

“With 70% of the Internet affected, the impact of PHP2Shell cannot be overstated.”

Sagi Tzadik, via wiz.io

Wiz Research says the vulnerabilities include memory disclosure and unauthenticated remote code execution in PHP itself, that every PHP version released in the last decade is affected by at least one of them (back to 5.4), and that the disclosed vulnerabilities are memory-safety issues in how PHP handles fatal errors.56 Wiz says it demonstrated unauthenticated RCE on WordPress, Drupal and Joomla, but that exploitation does not require one of these CMSs because the vulnerable code is in PHP itself.78

Wiz's timeline says it discovered the first vulnerability on August 19, 2026 using Wiz Atlas, Gemini 4 Argon, and GPT-5.6 Sol, reported it to the PHP security team on August 24, and that PHP acknowledged the reports on September 21.9101112 OpenAI's account differs in emphasis: it says Calif identified a critical flaw using GPT-5.6 Sol under its Patch the Planet initiative, with Wiz also independently discovering and reporting both vulnerabilities.13

Wiz calls the findings among the most severe in PHP and "arguably in software history," and says it believes the episode could mark a turning point for the AI era like Heartbleed and Log4Shell.1415 OpenAI says it considers this one of the most impactful security issues in recent memory, notes that the same AI capabilities could help attackers, and has committed $1 billion in subsidized Daybreak access for defenders.161718
