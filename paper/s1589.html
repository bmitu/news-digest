TorchTPU launch

From reports by Hugging Face, TechCrunch · Oct 20

Google announced on Tuesday that TorchTPU, its version of PyTorch, is now available as an open source project, which TechCrunch says puts Google alongside Amazon in trying to break Nvidia's hold on AI app development.12 TorchTPU lets AI apps run on Google's Tensor Processing Units (TPUs), and TechCrunch says existing PyTorch apps can be moved to TPUs and Google Cloud with a simple configuration change and no rewriting.34

TechCrunch says Amazon made a similar announcement on Monday, releasing TorchNeuron for its Trainium chip and AWS, and that Amazon is also submitting code to the main PyTorch project to decouple features from Nvidia's chips.56 TechCrunch says Google may be one-upping Amazon in a few ways: Google says it worked with Meta, Hugging Face, Inferact, RadixArk and others, and it launched a TPU agent suite to help developers migrate and fix errors.789

Hugging Face reports that Transformers, Diffusers and Kernels now run natively on TPU, and that Optimum TPU is no longer required to run Hugging Face models with Transformers and Diffusers.1011 Hugging Face reports that at batch size 64, a Hub kernel makes decoding 21.5× faster on Qwen3-30B-A3B and 12.8× faster on Gemma 4 26B-A4B than the default implementation, on a TPU v6e-8.1213 Hugging Face also says 96.5% of the tests that run on TPU pass, and that it has reported 34 issues on the TorchTPU repo, 19 of them already fixed. It admits the work is not finished.141516

TechCrunch cautions that developers will not necessarily abandon Nvidia hardware en masse, though it concludes that Amazon and Google are clearly working to end Nvidia's advantage.1718
