Survival LLM

Last scan Sat Oct 31, 06:24 UTC
2 sources · 541 points on Hacker News · single origin (Survival LLM)

Survival LLM is a free, open-source AI assistant and emergency library that runs entirely on a user's own computer; after setup (done while online) it needs no internet.12 Zvi Mowshowitz's newsletter AI #192 listed it under "Introducing", describing it as an offline set of resources plus an LLM, maximized to what the computer can handle, so that a user keeps basic world knowledge if the internet goes down.34

The project's own site says the library includes medical references, FEMA and CDC guidance, survival manuals, repair and how-to guides, and about 930,000 Wikipedia articles.5 The site also says setup takes 20 minutes to about 2½ hours, depending on the computer and internet speed, and that the library is a 9 GB download for everything (19 GB once installed).67

On first launch the app checks the computer's memory and downloads a model that fits; the site lists NVIDIA Nemotron 3.5 Super, Qwen3.8 27B, NVIDIA Nemotron 3.5 Lightning and IBM Granite 4.2 8B for different hardware tiers.89 The developers report that in their own blind-graded test of 22 blackout and first-aid questions, the four models listed (Nemotron 3.5 Super, Qwen3.8 27B, Nemotron 3.5 Lightning and Granite 4.2 8B) got the main point of official guidance right in 21, 21, 19 and 14 cases respectively, on an earlier build of the library.1011 The site cautions that smaller models make more mistakes, so every answer lists the articles it used so users can check the sources.1213

The site's update notes list version 0.3.4, dated October 27, 2026, which added a reasoning-limit setting and a retry when the AI looked things up but never wrote an answer; versions 0.3.1, 0.3.2 and 0.3.3 are also dated October 27, 2026, and 0.3.0 October 26, 2026.1415
