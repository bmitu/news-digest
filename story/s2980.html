Revolut self-hosts open models

Last scan Sun Nov 8, 08:53 UTC
2 sources · tracked since Nov 6 · 2 independent origins: The Register, Together AI

Revolut has reportedly cut its AI coding inference spend by about 90% by replacing hosted coding agents such as Claude Code and OpenAI Codex with self-hosted Z.ai GLM models, serving GLM-5.3 on 56 Nvidia B200 GPUs.1 Its reported optimizations include NVFP4 quantization, disaggregated prefill/decode, hyperparameter tuning and a practical context cap of around 256k tokens.2 Vision and UI tasks still route to commercial multimodal models, according to the report attributed to The Register.3

A second newsletter says Revolut made open models its coding default for about 2,000 engineers, citing one-tenth the cost and 70% faster lead time, attributing the point to Together Compute.4 Revolut claims roughly 60% faster coding time and about 70% improved lead time across around 2,000 engineers.5

Commenters framed the result as validation for self-hosted LLM infrastructure, arguing hosted coding tools were inflating costs rather than delivering "10x" engineers.6 One commenter said Revolut's engineering culture is relatively conservative, with engineers keeping control rather than using unrestricted "Claude YOLO" workflows.7 Others speculated the hardware might be modest, "like 6 DGX Sparks", and that more businesses could copy the pattern if their coding workload is steady enough to amortize GPU costs.89

The Revolut case was also cited in a thread about Goldman Sachs restricting Claude Code, where a commenter referenced Revolut allegedly moving toward local AI using GLM, tying this to concerns that hosted model vendors like Anthropic/OpenAI face pressure from on-prem/local inference economics.1011
