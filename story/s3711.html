AWS Emulator

Last scan Sat Nov 14, 15:53 UTC
2 sources · 111 points on Hacker News · single origin (AWS)

AWS has released AWS Emulator, which gives coding agents a local copy of AWS services to test against.1 The announcement states that the tool draws on over 400 API models spanning upwards of 200 AWS services, that agents handled all of its coding and testing, and that users can run it offline at no cost on their own computers.23 Simon Willison says the project is written in Rust by a large swarm of agents, with 29,684 commits in its first three weeks.4

Swaminathan Sivasubramanian says the idea came from Matt Goldberg, a Senior Principal Engineer, who hypothesized that an agent given a written service description and the real service to check against could build a working version on its own.567 Sivasubramanian says that when Goldberg gave Kiro a single prompt for an SQS emulator, it returned a passable first version in about 15 minutes.8

Agents work from fidelity tests, which are corrected until they pass against real AWS and then used to check the emulator, so a failing test points to a gap in it.910 Sivasubramanian says every change passes a merge gate of automated checks, including several security agents doing adversarial reviews.11 Sivasubramanian argues that when agents write code, the engineer's job is to build the specs, tests and merge gates that decide when the work is correct.12

Willison welcomes the release but notes it currently requires Docker on macOS or Windows, and hopes for a single downloadable binary usable across languages and platforms.1314
