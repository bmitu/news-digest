OpenAI Decisions API

Last scan Sat Oct 10, 12:51 UTC
2 sources · 2 independent origins: OpenAI, Simon Willison

OpenAI released a public beta of its Decisions API, a Jev-style service that returns typed answers instead of free text and runs on GPT-6 Luna. inference12 It offers three request types: the probability that a condition is true, a pick from a list, or a score against levels, and it accepts text and images.34 OpenAI says the API is up to 10x faster than its Responses API.56 Pricing starts at $0.10 per million input tokens with no output charge.78

Simon Willison notes that Jev charges 4.2 cents per million input tokens, so OpenAI's rate is higher. inference9 Willison writes that the API shape is conceptually very similar to Jev's, with the same three question types, but that gpt-6-luna also supports image input, which Jev does not.1011

Latent Space says several vendors shipped "decision" models on the same day, and that Jev is the reference point everyone benchmarks against.1213 Latent Space reports Vals found Jev matched GPT-6 Astra's 97.5% on claim verification at about 1/500th the cost, though Jev also ranked last on LegalBench, and that Theo argues model-routing use cases are "absolutely useless" for choosing intelligence levels.1415 An early evaluator cited by Latent Space says decision models still struggle on consistency and complex decisions.16
