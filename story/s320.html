Ultrafast tier

Last scan Tue Oct 6, 16:18 UTC
2 sources · tracked since Sep 30 · 2 independent origins: Latent Space, OpenAI

OpenAI announced Ultrafast, a premium speed tier that it says offers up to 8x faster token generation (300 tokens per second) in Codex and up to 6x in the API.12 Ultrafast is available today for GPT-6 Astra in Codex, ChatGPT Work and the API, with GPT-6.1 Sol coming soon, according to OpenAI's announcement as quoted by Zvi Mowshowitz.3 Latent Space reports pricing at 6x, i.e. $60/$300 per million tokens for Astra.4

Mowshowitz also says a new $500 tier with 25x base usage will include Ultrafast, while Pro users drop to 100 Pro messages per week and heavy coders' multiplier falls from 20x to 10x.56 Tibo defends the plan changes by saying users will still get more work done than on the $200 subscription a month ago, while Mowshowitz notes the API value per dollar is down by half. inference78

The hardware behind Ultrafast is disputed or unclear: Latent Space's DevDay recap says it runs on unspecified silicon, while a post it cites says SemiAnalysis reports it runs on NVIDIA GPUs at low batch sizes, not on Cerebras. inference910

A hands-on report cited by Latent Space says generation is about 8x faster, but end-to-end agent tasks speed up only 2–4x because tool latency dominates.11 The same report says gains are largest for computer use, since UI actions respond in milliseconds.12

Mowshowitz says he would want Ultrafast rather badly if ChatGPT were his baseline, but his primary is Opus, so he is not that tempted if OpenAI keeps not comping him.13
