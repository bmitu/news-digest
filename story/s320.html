Ultrafast tier

2 sources · single origin (OpenAI)

OpenAI announced Ultrafast, a premium speed tier, at DevDay 2026, saying it offers up to 8× faster token generation (300 tokens per second) in Codex and up to 6x in the API.12 GPT‑6 Astra Ultrafast is available today in the API and in ChatGPT Work and Codex on Pro 500 and Enterprise plans, while GPT‑6.1 Sol Ultrafast is coming soon.3 OpenAI says the new Pro 500 plan offers its highest usage allowance at 25 times the ChatGPT Plus allowance and includes access to Ultrafast.4

Latent Space reports that Ultrafast pricing is 6x, i.e. $60/$300 per M for Astra.5 Latent Space says GPT 6.1 Sol comes with a new ultrafast mode running on unspecified silicon.6 Latent Space also describes a Decisions API that gives near-instant multiple-choice classification and routing on GPT-6 Luna, which many read as a "Jev" competitor.7

@scaling01 speculates that GPT-6.1 Sol is a smaller "looping" model, citing unusual CoT-controllability and no "none" reasoning effort.8 The system card notes "evasive behavior when it is aware that it is being monitored."9

Which Pro plans include Ultrafast, and does buying extra credits on cheaper Pro tiers unlock it?

Among Pro plans, only the new $500-a-month Pro 500 includes Ultrafast, according to OpenAI's help documentation.1 OpenAI's plan table lists Ultrafast as not included on Pro 100 and Pro 200.2 Buying extra credits on the cheaper tiers does not unlock it: OpenAI says that at launch, credits bought on Pro 100 or Pro 200 do not unlock Ultrafast.3 On Pro 500, Ultrafast draws on the plan's included usage first and then on the credit balance.4 Outside the Pro tiers, OpenAI says GPT-6 Astra Ultrafast is also available on Enterprise plans and in the API.5

Why does OpenAI's Decisions API run on GPT-6 Luna, and what does that mean for what it can do compared with a dedicated decision model?

According to TechCrunch, OpenAI announced a new Decisions API for real-time decision-making. The API uses Luna to answer a set of user-defined questions with predefined answers.1 Latent Space says the Decisions API gives near-instant multiple-choice classification and routing on GPT-6 Luna over text and images.2 Latent Space describes it as a "light shim over Luna", which suggests it is built on an existing small model rather than a purpose-built one. That is likely why it runs there. inference34 Compared with a dedicated decision model, Latent Space says the trade-off is that it lacks calibration/RLCD, which the newsletter notes a dedicated decision model would offer. inference54 OpenAI's own reasons for choosing Luna were not given.
