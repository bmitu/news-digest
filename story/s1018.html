Reflection releases Beam

Last scan Wed Oct 21, 20:11 UTC
3 sources · tracked since Oct 17 · 1 new article this week · 2 independent origins: Latent Space, Reflection

Reflection has released Beam 1.0, its first model, as an open-weight mixture-of-experts model with 501B total parameters and 23B active per token, a 1M-token context window and an Apache 2.0 license.123 The release includes BF16, FP8 and NVFP4 weights, a DFlash2 speculative-decoding drafter, the open Mirror CLI harness Beam was trained on, and a safety report.4 Hugging Face notes that all 256 experts stay in memory, so deployment needs the memory of a 501B model while running at roughly the speed of a 23B one, and that the BF16 checkpoint is about 1 TB.56

Artificial Analysis scores Beam 30, which it ranks second among US open models, using about 26k tokens per task.7 Results are uneven: it reaches 48.5% on AutomationBench-AA but only 3.0% on Terminal-Bench 4.0, and on AA-Omniscience it answers 33% correctly while hallucinating at 47%.89 Arena places Beam 12th among open models in Agent Arena and says it is the only non-Chinese model in the top 25 open models on Code WebDev.10

Interconnects calls Beam the strongest open American model released under a permissive license, though it says it is not the smartest open model available.11 Interconnects praises its token efficiency, second only to GPT-6-Astra, as a sign of a well-developed post-training stack.12 On X, @teortaxesTex calls Beam "DOA" against the smaller, MIT-licensed DeepSeek V4.1 Flash.13
