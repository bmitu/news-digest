Reflection releases Beam

Last scan Sat Oct 17, 12:46 UTC
3 sources · 2 independent origins: Latent Space, Reflection

Reflection, a new US AI lab, has released Beam, a 501-billion-parameter mixture-of-experts model with 23 billion active parameters per token, under the Apache 2.0 license, according to Hugging Face.1234 Hugging Face says Beam has a 1M-token context window, is focused on coding and agentic use, and has day-0 support in transformers, SGLang and vLLM.567 The release includes BF16, FP8 and NVFP4 weights, a DFlash2 drafter and an open harness called Mirror CLI, which Beam was trained on.8

Reflection says Beam was pre-trained on 6,144 GB300 NVL72 GPUs for four weeks, using 23.8 trillion tokens, followed by four weeks of reinforcement learning on about 10.5K of the same GPUs.910 Reflection claims Beam matches GLM-5.2 on advanced reasoning benchmarks while using 3–4× less inference compute, and says its RL run used one million coding, agentic and STEM environments, which it believes is among the largest by any open lab.1112

Independent results are mixed: Artificial Analysis (AA) scores Beam 30, #2 among US open models, at about 26k tokens per task.13 AA found 48.5% on AutomationBench-AA but only 3.0% on Terminal-Bench 4.0, and a 47% hallucination rate on AA-Omniscience with 33% answered correctly.1415 Arena ranks Beam #12 among open models in Agent Arena and the only non-Chinese model in the top 25 open models on Code WebDev.16

Import AI says Beam's benchmark scores trail frontier Chinese models such as those from Zhipu, Moonshot and DeepSeek, citing MCP Atlas of 78.7 versus 84.2 for GLM-5.3.1718 Import AI argues that models like Beam give the US a chance to return to the open-weight frontier, which it says it fell off largely because Meta stopped making good LLaMA models.1920
