Chinese-linked hackers use Cairn AI agents to exploit zero-day

Last scan Thu Nov 26, 05:11 UTC
2 sources · tracked since Nov 22 · 1 new article today · single origin (Amazon)

According to Amazon Threat Intelligence, hackers tied to China relied on Cairn, an AI-driven tool that carries out penetration testing on its own, to discover and take advantage of what seems to be a previously unknown flaw in East Asian servers, among them a university's system and software for medical imaging.1 According to Amazon, the agents received only a list of IP addresses and the goal "obtain shell access," and the prompts were in simplified Chinese with the model set to Chinese Standard Time.2

The agents reportedly found a path traversal flaw in an open-source medical imaging AI application's upload endpoint, going from mapping the API to writing arbitrary files in about 11 minutes.34 In a later session they used the flaw to plant a Python reverse shell payload and obtained a reverse shell running as root.5 Amazon assesses with high confidence that this was a zero-day, citing the absence of any fix, issue, advisory or prior mention in vulnerability databases.6

Not every attempt worked: agents spent more than 16 hours on Redis and Log4Shell attacks without success, and a six-hour effort against a university GPU server using 80 usernames and 30,000 credential combinations also failed.789 Humans re-entered the loop later, giving the agents a proxy tunneled into a second university network that Amazon infers was compromised with the same zero-day.1011

Ars Technica notes that Cairn is open source and model-agnostic, and that Palo Alto Networks earlier said hackers used it in a campaign of 25 autonomous operations against at least 19 organizations, with at least 10 breached.1213 Amazon warns that defenders should prepare for the speed and persistence of such tools, saying an agent that exploits a zero-day in minutes works faster than many security operations centers can triage an alert.1415
