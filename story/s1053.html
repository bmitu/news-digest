FLUX 3 Image Klein

Last scan Sat Oct 17, 12:46 UTC
2 sources · single origin (Black Forest Labs)

Black Forest Labs released FLUX 3 Image Klein, an open-weights text-to-image, image-editing and multi-reference model, which one summary describes as a distilled 5.6B model under the FLUX Kommunity License.12 Another recap says the model offers native 4K output, bounding-box control and multi-reference editing.3

Hugging Face says the model runs in Diffusers from day one, with bounding boxes written into the prompt to control layout.45 Hugging Face also says the distilled checkpoint makes a 1024 × 1024 image in about 2 seconds on an H100 and 16 steps by default.67 Black Forest Labs ships the transformer as a single file in bf16, rowwise FP8 and nvfp4 formats, according to Hugging Face, and the model uses a Qwen3-VL-4B-Instruct text encoder according to the Reddit summary.89

On ComfyUI, an official weights repo reportedly includes BF16, INT8 and NVFP4 variants, though its README initially said public ComfyUI lacked a FLUX 3 Image loader, and an edit says Kijai committed support.1011

Early user testing was broadly negative: one commenter said "the model is trash," and others said it underperforms Krea with frequent anatomy errors and weaker prompt and world knowledge.1213 One tester said it "knows a fraction as much as krea" and called it "the most censored model yet."14
