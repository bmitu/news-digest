DeepSeek V4.1 Flash 1017 release

Last scan Sat Oct 17, 12:46 UTC
2 sources · 455 points on Hacker News · single origin (DeepSeek)

DeepSeek released DeepSeek-V4.1-Flash-1017, which it describes as a minor update to DeepSeek-V4.1-Flash with substantial improvements in reasoning, coding, agentic tasks and visual benchmarks.1 DeepSeek says the model also reduces task execution time and output length, letting users finish tasks faster and at lower cost.2 OpenRouter lists it as the October 17, 2026 snapshot of V4.1 Flash, served under the deepseek-flash API model name.3

In DeepSeek's own benchmark table, the new version scores 42.6 on HLE without tools versus 36.8 for the prior Flash, 42.3 versus 31.2 on Terminal-Bench 4.0, and 77.0 versus 74.2 on DeepSWE v1.1. inference456 The same table shows it ahead of the listed competitors on several agentic benchmarks, such as ProgramBench at 29.1 and Apex Bench v1.1 at 72.1, though one listed model scores higher on others, including 56.3 on HLE and 51.8 on Terminal-Bench 4.0. inference789

OpenRouter describes V4.1 Flash as a sparse mixture-of-experts model, activating 8B parameters on input and 16B on output from a 552B-parameter backbone, with native image understanding.1011 OpenRouter lists pricing of $0.10/M input and $0.50/M output tokens and a 1,048,576-token context window, while DeepSeek's repository states MIT licensing for the weights. inference121314 OpenRouter says DeepSeek positions the Flash line as the cost-efficient tier of V4.1 and reports that it exceeds V4 Pro on performance, speed and task completion time.15
