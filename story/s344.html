Decisions API

2 sources · tracked since Sep 30 · 2 new articles today · 3 independent origins: Latent Space, OpenAI, TechCrunch

At OpenAI's Dev Day on Tuesday, CEO Sam Altman revealed, in an aside, a new "Decisions API" that TechCrunch says apparently provides similar functionality to Jev, a model released earlier this month by TypeSafe AI.12 Altman described it as a way to give OpenAI's Luna model a predefined set of options to choose between, saying that focusing the model on that choice makes it extremely fast while keeping image understanding, broad language support and safety protections.34

The Latent Space newsletter says Decisions API gives near-instant multiple-choice classification and routing on GPT-6 Luna over text and images, and that many read it as a Jev competitor.5 Latent Space's newsletter also describes it as, for now, a light shim over Luna that gets vision but comes without calibration/RLCD, and OpenAI's Nikunj Handa says the first version is zero-shotting the task on top of Luna, with the Latent Space podcast summary calling it a Luna wrapper for now.678 Handa says OpenAI will put it out as classic iterative deployment and make model improvements as needed, and TechCrunch notes it is only a limited preview, so it is unclear how similar it will be to Jev.910

TypeSafe CEO Diogo Almeida joked on X about the beginning of the clone wars and suggested OpenAI's interest could be a sign that building in a System One compatible way is the future.1112 TechCrunch says a key question for such decision models is how well calibrated their outputs will be to real life, and that Almeida says his company's moat is the synthetic data it creates.1314

How much cheaper is a Jev-style decision model than a frontier LLM for something like monitoring AI agents?

In a hackathon demo built by QueryStory's Shapor Naghibzadeh, monitoring AI agent actions cost $2.94 with Jev versus $372 with a frontier LLM, which is roughly 126 times cheaper. inference1 A separate Jev-as-a-Judge paper reports that Jev costs $0.044 per 1K judgments, about 277× cheaper than GPT-6.2 That judging comes with a quality tradeoff: Jev stays within 3 points on RewardBench and HaluEval but trails by 14.5 points on JudgeBench.3 A cascade that escalates low-confidence calls to GPT-6 Astra keeps 99% of accuracy at 57% of the cost, a much smaller saving than using Jev alone. inference45

Could a decision model like this be used to watch AI agents for bad actions, and how would that help after OpenAI's agent incidents?

Yes, TechCrunch reports that monitoring and securing AI agents is one likely application of decision models like Jev and OpenAI's new Decisions API.1 TechCrunch reports that one of OpenAI's new security measures, following a series of incidents where its agents misbehaved on the open internet, is using a separate model to watch for bad actions at "significant compute cost."23 Cybersecurity professional Shapor Naghibzadeh, who leads QueryStory, thinks a Jev-like model could make that monitoring far cheaper, and his hackathon demo uses Jev to check each agentic action against its assigned task, blocking actions it had high confidence were bad, flagging others for review, and permitting the rest.456 Because Jev is arguably cheap enough to run on every agentic action, it could add a layer of review that improves agent reliability, but OpenAI's Decisions API is currently a limited preview and a light shim over Luna without calibration, and how well calibrated such models are to real life remains a key open question. inference78910

How does the Decisions API differ from the models OpenAI uses for computer use, and what is it worse at?

OpenAI's Ari Weinstein says the Decisions API is a smaller model than the ones used for computer use, with no reasoning and parallel inference, which makes it really fast.1 Per Weinstein, those same traits make it somewhat worse at long-horizon, sophisticated tasks.2 It is also built for a narrower job: OpenAI says it focuses Luna on user-defined questions with finite, pre-defined answers, such as classifying content, routing requests or choosing an agent's next action, using text or images.345 For now it is a light shim over Luna, according to Latent Space, so it gets vision but lacks calibration/RLCD.67
