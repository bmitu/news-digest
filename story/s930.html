Harvard study finds AI coding agents raise code output but not software output

Last scan Mon Oct 19, 23:45 UTC
2 sources · 364 points on Hacker News · tracked since Oct 10 · single origin (Ars Technica)

The study used Jellyfish data covering 300 million work events across more than 700,000 employees at over 700 software firms from 2021 through March 2026.1 The researchers report that introducing AI coding agents led to a 30 percent increase in lines of code, a 20 percent rise in commits and a 23 percent increase in pull requests on average.2 However, the resolution rate for Jira-tracked Issues and Epics did not change in a statistically significant way after AI tools were introduced.3

The authors' data show that average review time between a pull request's submission and merge rose 49 percent, the share of pull requests with changes requested nearly doubled, and comments per pull request rose 35 percent after AI agents were introduced; Ars Technica says the discrepancy can be found in the code review process.45 The share of workers performing code reviews rose 14 percent, and the researchers say they cannot attribute significant employment changes to AI.67 AI review tools have so far had a marginal effect: although 80 percent of measured firms used some AI code review by March 2026, AI agents accounted for only 23.3 percent of review comments and 10.8 percent of pull requests.8

Ars Technica's Kyle Orland notes that agents have been significantly updated since the study's March 2026 data cutoff and that these trade-offs could improve as teams gain more experience with AI agents.910 Orland concludes that the result makes him wonder whether the time and expense of getting AI coding agents working is worth it for most companies.11
