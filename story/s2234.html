Claude Code VS Code extension backdoor

Last scan Sat Oct 31, 06:24 UTC
4 sources · 1892 points on Hacker News · 4 independent origins: Ars Technica, Kevin Beaumont, Matt Jay, Phorion

An official Anthropic Claude extension for VS Code, distributed through the Cursor marketplace, was backdoored, and Cursor said the malicious version 2.1.313 affected "at most 5,000 users".12 A Latent Space newsletter briefly relayed the incident as a report that the official extension was compromised, saying pulling it in a brief window would have installed an SSH backdoor.3 Independent researcher Kevin Beaumont said Anthropic pushed version 2.1.314 several hours after the bad version appeared, and Beaumont and Phorian's Luke Roberts said 2.1.313 went out through Anthropic's official Cursor account.45

Cursor said the extension tried to install a persistent SSH backdoor by adding an attacker-controlled SSH key, enabling the local SSH service and opening a reverse SSH tunnel, with code written for Windows, macOS and Linux.67 It also collected host and user details such as hostname, username, environment variable names and public IP, which Phorion said let the operator inventory cloud credentials and API tokens, likely to prioritize follow-up targets.89 Bugs in the malicious code for Windows and macOS prevented the backdoor from working in some cases, but Phorion said it remains a significant threat that installs persistence and beacons reconnaissance to the operator.1011

Cursor said it worked with the hosting cloud provider to cut infected devices off from the server, removed the backdoored version, blocked further distribution, and briefly shut down the VSCode Marketplace to rotate keys and audit access; the marketplace is now open.1213

Ars Technica says anyone who installed or updated the extension from Cursor between 5:27 am ET and 4:35 pm on Thursday should consider themselves affected.14 How attackers gained control of Anthropic's account is still unknown, according to Ars Technica, and neither Cursor nor Anthropic answered its questions seeking this information.1516
