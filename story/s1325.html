Linus Torvalds uses LLMs on assoc_array code

Last scan Tue Oct 20, 08:37 UTC
2 sources · tracked since Oct 17 · 1 new article this week · single origin, unclear which

Linus Torvalds described a fixes branch for the kernel's assoc_array code as LLM-assisted, using modern LLM tools to make obscure code easier to understand.12 The work began after Nils Ollrogge reported and patched a bug.3 Torvalds then ran the refactored result through a userspace test harness, which reproduced the reported bug and found three additional bugs.4 All of these bugs were apparently present since the library's initial 2013 commit.5

Top comments on the Reddit thread, as summarized, framed it as a credibility boost for AI-assisted systems programming, treating LLMs as a productivity multiplier for experts rather than a replacement.67 Commenters stressed that the interesting use was code comprehension rather than blind code generation, and that Torvalds still had to verify the explanation against actual kernel behavior.89 One thread compared AI output to compiler output, suggesting AI may become another abstraction layer if its output remains reviewable and maintainable.1011 The thread also showed an unresolved divide: critics argue AI code can be messy, inefficient and hard to maintain, while supporters say outcomes depend heavily on user skill and review discipline.12
