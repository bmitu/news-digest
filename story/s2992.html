OpenAI acquires Pierre Computer Company

Last scan Sun Nov 8, 08:53 UTC
2 sources · 263 points on Hacker News · tracked since Nov 6 · single origin (OpenAI)

OpenAI announced that it will acquire Pierre Computer Company, Inc., the company behind Code Storage and a family of open-source developer tools.123 The deal is subject to customary closing conditions, including regulatory approvals, and until closing the two companies remain separate and independent.45

OpenAI says users of the Codex app have already used Pierre's Trees and Diffs libraries for browsing files and reviewing changes.6 OpenAI praises Pierre's work, saying Trees and Diffs make it easy to review large volumes of code, Diffs' Edit mode lets reviewers fix code in place, and Pierre recently released Highlights, a fast syntax highlighter.789

OpenAI says it wants to work with the Pierre team to adapt Git workflows to how teams work with coding agents, noting that it recently shared how it is scaling Git internally with Pando, its in-house source control backend.1011 OpenAI describes its ambition as setting the standard for modern software development, from an agent's first branch to deployment, and making Codex the place for developers' and agents' most ambitious projects.1213

OpenAI says Pierre's open-source projects will remain open-source and that customers can keep using Code Storage after closing while it works to bring its features into Codex.1415
