CPU built inside Qwen weights

Last scan Sat Oct 31, 06:24 UTC
4 sources · 215 points on Hacker News · single origin (Drew Breunig)

A project called Qwenputer, by Divyansh Agrawal, claims to embed a 32-bit RISC-V virtual CPU into the weights and layers of Qwen3.5-4B, with a Hugging Face model, a write-up and a live demo.123 Commenters who looked into it described the mechanism as native tool execution: when Qwen emits a <tool_call> such as calc, put, get or list, added "computer layers" intercept it during the forward pass, run the code on the virtual RISC-V processor, and write the <tool_response> back token by token.45

Top commenters were skeptical that this meaningfully improves on ordinary tool calling, calling it a clever but likely inefficient novelty.6 The main plausible benefit raised was stronger sandboxing, since execution happens inside a constrained virtual environment, though likely at high computational overhead.78 Another commenter preferred the inverse approach, hardware with Qwen-like weights implemented directly in circuits, while noting that current projects are too expensive for mass use.9

Drew Breunig, inspired by Qwenputer, then built "nesformer", which bakes a working emulator of the Nintendo Entertainment System's 6502 CPU into the weights of Qwen3.5-4B, so NES ROMs such as Super Mario Bros can run, very slowly, inside Qwen.1011 The nesformer project says nobody trained the weights because a compiler computed every one, and that it reuses Qwenputer's compiler and its central trick of using the model's Gated DeltaNet state as the machine's memory.1213 Breunig reportedly used Opus 5.5 prompts to build it, and Opus apparently found and used a collection of NES CPU conformance tests released 15 years ago by Christopher Pow.1415

The project reports that every CPU token came from the model and that frames for the bundled test games match a conventional 6502 emulator exactly, but it is slow: a frame takes 1–6 seconds, and it runs 150–290× slower than the real console.161718 It is limited to NROM cartridges (iNES mapper 0) and official opcodes, and it cannot yet follow bank switching.192021
