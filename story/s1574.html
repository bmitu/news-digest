DeepSeek releases DeepInfer

Last scan Wed Oct 21, 20:11 UTC
4 sources · 2291 points on Hacker News · single origin (DeepSeek)

DeepSeek released DeepInfer, the inference framework that powers its large-scale production services, as an open-source offline-inference release supporting DeepSeek-V4.1-Flash.12 The release targets NVIDIA SM100 GPUs and Huawei Ascend 950 NPUs, is under the Apache License 2.0, and includes features such as speculative decoding, SWA bounded replay, batch-invariant inference and structured outputs.345 DeepSeek also released deepseek-recipe, a Rust library with Python bindings for protocol conversion and model-output parsing across API formats such as Chat Completions, Messages and Responses.6

Interconnects says estimates point to DeepSeek making up to 90% gross margin selling tokens on this stack, and the Latent Space headline cites roughly 80% margin. inference7

The release is not a complete serving stack: the GitHub page lists a KV cache system, prefill/decode disaggregation and load balancing across data-parallel replicas as required for a complete service but not included.8910 Latent Space reports that the vLLM team, after acknowledging DeepInfer was initially built mainly on vLLM, said decode throughput came within 6% of DeepInfer's published results on GB200 under a matched configuration.11 Interconnects, by contrast, says DeepInfer is likely far more efficient than open tools like vLLM/SGLang for DeepSeek's models.12

Interconnects calls it one of the bigger open-source AI artifacts in recent months and expects inference companies to adopt the tools quickly, which it says will push down prices for DeepSeek's models or raise margins.1314 Reddit commenters were surprised that DeepSeek open-sourced an internal production stack, while some questioned whether it is general-purpose or mainly optimized for DeepSeek's own architecture.1516
