Anthropic launches Claude Ship

Last scan Sat Nov 28, 09:22 UTC
2 sources · tracked since Nov 25 · single origin (Anthropic)

Anthropic has launched Claude Ship, a product that lets Claude review, fix and approve pull requests, with the announcement made on a Monday according to TechCrunch.12 Claude Ship combines the already generally available Code Review feature with two new beta agents, PR Steward and Claude Approvals.34 Claude Ship is available to Claude Team and Enterprise customers and works with GitHub repositories.56

Anthropic says PR Steward steps in on failing CI checks, merge conflicts and review feedback, and leaves comments describing what it changed.7 TechCrunch also reports that after each push, PR Steward leaves a comment explaining what it modified and describing the steps for undoing the change should that be necessary.8

If an organization's policy permits, Claude Approvals is able to sign off on routine changes, relying on indicators like findings from Code Review or classifiers a team has authored in plain natural language.91011 Because the approval feature is in beta, Anthropic suggests first running it in observe-only mode, and teams can start with one repository and set monthly spending limits.1213 Anthropic says teams keep control over where Claude Ship runs, which review settings to use, and which changes get escalated to a human.14

TechCrunch regards the automatic approval agent as the most interesting and notable part, since other AI coding tools already offered code review, and frames the launch as a response to review bottlenecks as AI agents generate more code.1516 An Anthropic blog post, quoted by TechCrunch, says that on the Claude Code team Claude writes most of the code and the company wanted everything after the PR to move as fast.17
