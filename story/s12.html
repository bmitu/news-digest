TypeSafe Jev decision model launch

Last scan Sat Oct 3, 04:20 UTC
3 sources · 157 points on Hacker News · tracked since Sep 27 · 3 independent origins: Allan Bo, TechCrunch, TypeSafe AI

OpenAI CEO Sam Altman revealed a new "Decisions API" at OpenAI's Dev Day on Tuesday, which TechCrunch says apparently provides similar functionality to Jev, a model TypeSafe AI released earlier this month.12 Altman described it as a way to give OpenAI's Luna model a predefined set of options, saying that focusing the model on the choice makes it extremely fast while keeping capabilities such as image understanding and safety protections.34 TechCrunch says it is unclear how similar the Decisions API will be to Jev, since it is a limited preview, and that a key question is how well calibrated such models' outputs are.56

TypeSafe CEO Diogo Almeida joked on X about the beginning of the clone wars and said OpenAI's interest could be "a sign…that building in a System One compatible way is the future"; TypeSafe did not respond to TechCrunch's questions about the new product.789 Latent Space reports that TypeSafe is reportedly raising $1B+ at a $10B+ valuation, a week after a $200M round, and that Jev is trained with RL to return typed decisions with probabilities rather than reasoning text.1011

A Jev-as-a-Judge paper reports Jev costs $0.044 per 1K judgments at 152ms median latency, about 277× cheaper than GPT-6, staying within 3 points on RewardBench and HaluEval but trailing by 14.5 points on JudgeBench.1213 The paper also says a cascade escalating low-confidence calls to GPT-6 Astra keeps 99% of accuracy at 57% of the cost.14 The post also challenges Jev's "0% hallucination" framing, noting that Typesafe's own explanation only guarantees outputs conform to the allowed schema, not that the chosen class is factually correct.1516

Commenters were split: some likened Jev to spaCy and scikit-learn classifiers, while one argued that scaling zero-shot classifiers could still be commercially valuable.1718 A separate post presents CLM as an open-weights, self-hostable replacement for Jev, implemented as a new projection head for Qwen3-8B, claiming 4×–13× lower latency in agent-style benchmarks, while stating limitations versus Jev including weaker zero-shot breadth (BFCL v4 95.2% vs 99.2%) and shorter calibrated context (2K–8K vs 64K); top commenters dispute the "Jev competitor" framing.192021

QueryStory's Shapor Naghibzadeh built a hackathon demo using Jev to check each agentic action against the task it was given; TechCrunch says monitoring of that kind costs $2.94 with Jev versus $372 with a frontier LLM.2223

What is Amazon's Strands Decider 2B, and what model is it built on?

Amazon's Strands Decider 2B is an open-source decision model from Amazon Web Services, inspired by TypeSafe's Jev.1 It sorts between pre-decided options and reports how confident it is in its choice, and it is fast, low-cost and small enough to run locally.23 It is built on the "torso" of an LLM, Qwen3.5-2B, but it outputs calibrated choices instead of generating text.45 Amazon distinguished engineer Marc Brooker started the project after seeing Jev, and it briefly topped the Jevbench ranking for models of its size before Amazon engineers cleaned it up and released it through Strands Labs.67 Brooker says it suits workflow steps because confidence scores and a closed set of answers make them more reliable, with potentially lower latency and cost.89

Why did TypeSafe name the model Jev, and what does the name mean?

TypeSafe named its model Jev after the economist William Stanley Jevons, and the name is meant to invoke Jevons's theory that the falling cost of something, such as computer intelligence, can increase demand for it. inference123
