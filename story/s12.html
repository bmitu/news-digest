TypeSafe Jev decision model launch

3 sources · 156 points on Hacker News · tracked since Sep 27 · 1 new article today · 3 independent origins: Allan Bo, TechCrunch, TypeSafe AI

At OpenAI's Dev Day on Tuesday, CEO Sam Altman revealed a "Decisions API" that TechCrunch says apparently offers functionality similar to Jev, a model TypeSafe AI released earlier this month.12 Altman described it as giving the Luna model a predefined set of options to choose between, saying that focusing the model on the choice makes it extremely fast while keeping capabilities like image understanding.34 TechCrunch says it is unclear how similar Decisions API will be to Jev since it is a limited preview, and that a key question is how well calibrated such models' outputs are.56

TypeSafe CEO Diogo Almeida joked about the start of the clone wars and said OpenAI's interest could be a sign that building in a System One compatible way is the future; TypeSafe did not answer TechCrunch's questions.789 Latent Space reports TypeSafe is reportedly raising $1B+ at a $10B+ valuation, a week after a $200M round.1011

Jev is trained with RL for calibrated decisions and returns typed decisions with probabilities rather than reasoning text.1213 A Jev-as-a-Judge paper reports a cost of $0.044 per 1K judgments at 152ms median latency, about 277× cheaper than GPT-6, within 3 points on RewardBench and HaluEval but 14.5 points behind on JudgeBench.14151617 In a security demo, QueryStory's Shapor Naghibzadeh used Jev to check agent actions, and TechCrunch says such monitoring costs $2.94 with Jev versus $372 with a frontier LLM.1819

A Reddit post argued Jev is not a new model class but standard constrained-choice classification, citing an external Banking77 baseline where BGE-small plus logistic regression reportedly scored 93.3% versus Jev's 83.2%.20212223 The post also challenged Jev's "0% hallucination" framing, noting TypeSafe's explanation only guarantees schema-conforming outputs, not factual correctness.242526 Commenters were split between skepticism and pragmatism, with one arguing that scaling zero-shot classifiers could still be commercially valuable.272829 A separate post presented CLM as an open-weights alternative to Jev, claiming 4×–13× lower latency in agent-style benchmarks but admitting weaker zero-shot breadth (BFCL v4 95.2% vs 99.2%); commenters disputed that it is a true Jev competitor.30313233

Is OpenAI's Decisions API a newly trained model, or is it built on the existing Luna weights?

OpenAI's Decisions API is not a newly trained model: OpenAI's Nikunj Handa says the company has not trained a new model for it.1 Handa says OpenAI is building it purely on top of the same Luna weights it already has.2 Latent Space describes it as, for now, a light shim over Luna, so it gets vision, without calibration/RLCD.3 This matches Sam Altman's description at DevDay, where he said the API gives the Luna model a predefined set of options to choose between.4 However, TechCrunch notes it is unclear how similar the API will be to Jev, because it is only a limited preview.5

How well does Jev hold up in real production use, such as reranking at Ramp or on OpenRouter?

On OpenRouter, Jev is reported as the top model at 1K–10K context, and turbopuffer's native reranking also includes it.1 Ramp reportedly matched the reranking accuracy of GPT-5.6 Luna using Jev, with 10× lower tail latency (300ms) at 3× lower cost.23 A hackathon demo by QueryStory's Shapor Naghibzadeh used Jev to check each agent action, at a reported cost of $2.94 versus $372 with a frontier LLM.45 However, its own judge paper shows limits: Jev stays within 3 points on RewardBench and HaluEval but trails by 14.5 points on JudgeBench, according to the paper as summarized by Latent Space.6 Commenters framed Jev as primarily a scaled/generalized zero-shot classifier, and one external Banking77 baseline reportedly had BGE-small plus logistic regression scoring 93.3% against Jev's 83.2%.78 Overall, the evidence is mostly positive but thin: TechCrunch says it has not seen developers testing OpenAI's rival product, and the key open question is how well calibrated these decision models are in real life. inference9

How does a Jev-plus-GPT-6 cascade work, and how much accuracy and cost does it save?

A cascade that escalates low-confidence calls to GPT-6 Astra keeps 99% of accuracy at 57% of the cost, and the Jev-as-a-Judge paper reports it costs 57% of the all-GPT-6 approach, which is roughly a 43% saving. inference1 Escalation is meant to cover the gap left by Jev alone, which stays within 3 points of GPT-6 on RewardBench and HaluEval but trails by 14.5 points on JudgeBench. inference2 The paper reports Jev costs $0.044 per 1K judgments at 152ms median latency, about 277× cheaper than GPT-6.34 Commenters on a Reddit post framed Jev as primarily a scaled zero-shot classifier, and a recurring view was that it should be evaluated on classification workloads rather than treated as a drop-in LLM substitute.56
