Codex updates

2 sources · single origin (OpenAI)

At OpenAI's DevDay on Tuesday, OpenAI introduced new Codex capabilities, headlined by reusable cloud development environments that can be accessed from any device.12 TechCrunch says the change makes cloud environments more persistent and configurable rather than isolated remote sandboxes, and OpenAI says they are designed to help tasks start faster and give teams a shared workspace with approved settings and permissions.34

The refreshed Codex CLI lets developers start and direct tasks by voice, adds an /agents view to delegate and track multiple tasks, and gets a "cleaner" terminal interface.567 Codex also comes to a new code review experience in the ChatGPT desktop app, including automatic initial reviews while users are away.89

OpenAI is also launching Codex Security Cloud, which can scan GitHub repositories on demand, on a schedule or on new commits, then investigate findings, remove duplicates and prepare fixes in the cloud even when the user's laptop is closed.1011 The tool set includes access to models from OpenAI's cybersecurity initiative Daybreak Blue without a separate application.12

On the API side, OpenAI announced a Decisions API that uses Luna to answer user-defined questions with predefined answers, and an updated Agents API supporting computer use and Amazon's Bedrock Managed Agents.1314 Latent Space notes that many read the Decisions API as a competitor to "Jev", and that for now it is a light shim over Luna.1516

How much faster is the new Ultrafast mode, and what does it cost compared with standard pricing?

OpenAI says its Ultrafast tier generates tokens up to 8x faster in Codex, at 300 tokens per second, and up to 6x faster in the API.12 Pricing for Ultrafast is 6x standard, which works out to $60 input and $300 output per million tokens for GPT-6 Astra, according to Latent Space.3 Ultrafast is available today for GPT-6 Astra in the API and in ChatGPT Work and Codex on Pro 500 and Enterprise plans, while GPT-6.1 Sol Ultrafast is coming soon.4 On ChatGPT, Ultrafast is included only in the $500-a-month Pro 500 plan, and not in the $100 or $200 Pro plans.56 OpenAI did not say what Ultrafast costs for GPT-6.1 Sol, whose standard prices are $2 per million input tokens and $10 per million output tokens. inference78

When will the Decisions API be available to all developers, and what can it be used for?

OpenAI says the Decisions API is in limited preview now, with a broad release planned in the coming days.1 No exact date for general availability was given. OpenAI says the Decisions API enables real-time decision-making by focusing Luna's intelligence on a specific set of user-defined questions with finite pre-defined answers.23 Developers supply context as text or images, and they can use the answers to classify content, route requests, or choose an agent's next action.45 Latent Space describes it as near-instant multiple-choice classification and routing, and says many read it as a competitor to "Jev".6
