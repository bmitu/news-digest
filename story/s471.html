How is DeepSeek Harness built, and what does its 'everything is a plugin' design based on Cordis mean for users?

DeepSeek describes DeepSeek Harness as an open-source harness built on Cordis's "everything is a plugin" architecture.1 It can be run as a desktop app or launched as a web UI from code, and it is in public preview worldwide.23 Latent Space's roundup notes desktop builds for macOS and Windows, with Linux users installing from npm, and says @omarsar0 frames such releases as a shift toward malleable harnesses.45 For users, DeepSeek says plugins can be installed, or created through chat in "Creator mode", to extend tools, skills and the interface.6 In DeepSeek's demo, a request to write a Pomodoro timer plugin resulted in a floating Pomodoro timer that was built, installed and verified, with the demo showing "Took 5m 24s".78 Users can start with a single npx command or clone the source, though DeepSeek warns the core plugins and APIs are still evolving in preview.910

Is DeepSeek Harness free and open source, and how stable is it given that it's only a public preview?
