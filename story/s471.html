What is Cordis's "everything is a plugin" architecture, and why did DeepSeek build Harness on it?

DeepSeek describes Harness as an open-source harness built on Cordis's "everything is a plugin" architecture, now in public preview worldwide with composable plugins that extend what agents can do.12 In practice, DeepSeek says users can install plugins, or create them through chat in "Creator mode", to extend tools, skills and the interface.3 DeepSeek's demo shows a floating Pomodoro timer plugin being built, installed and verified from a chat request in 5 minutes 24 seconds.456 DeepSeek's own explanation of why it picked Cordis, and a detailed definition of the architecture beyond the plugin framing, were not given; it only links a "Cordis paper".

Is DeepSeek Harness open source, and how stable is it? Will the core plugins and APIs change during the preview?

DeepSeek describes DeepSeek Harness as open source and in public preview worldwide.1 The source is published on GitHub, and it can also be launched with a single npx command.23 On stability, DeepSeek labels the product a preview and says its core plugins and APIs are still evolving, so changes during the preview should be expected.4 Several features inside the app are labeled Experimental, including Agent teams, Auto approval review, Scheduled tasks and Voice input.5 No specific list of which plugins or APIs will change, nor any timeline or stability guarantee, was given, and the license was not named.
